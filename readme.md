# 项目指南

## 1. 编译 Vue3 项目
```bash
cd web
npm install
npm run build
```

```bash
cd server
python manage.py 
```

## 2. 迁移 Django 数据库
```bash
cd server
python manage.py makemigrations
python manage.py migrate
```

## 3. 上传到 GitHub
```bash
git add .
git commit -m "完成侧选框与内联表关联"
git push origin main
```
